# Harbour View Demo

A fictional demo of a hotel and restaurant operations system. Every name, place, vendor, and figure is made up.

## Run it

Open `index.html` in a browser. No server or install is needed.

Or serve the folder locally:

    npm run start

## Demo sign-in

Changes stay in the browser only. Nothing is sent to a server.

## Files

- `index.html`: the whole demo app (single page).
- `logo.png`, `icon-512.png`: resort crest and app icon.
- `vercel.json`: static hosting settings for Vercel.
- `CHANGELOG.md`: version history.

## Deploy

Import this repository in Vercel as a new project. It needs no build step.
